# unitime
## Project Overview
A Platform and a scheduling system for college students.
- Students can view exam results
- Students have access to a Scheduling Assistant that lays down priority (sorts them) of each course to help students build a schedule.
- Admins can input exam results
- Admins can view rooms available and their features and book them.
- Students and admins can view their personal schduel but admins view students'.
- Students can view Events, the rooms its held in and their groups.
- Load tasks from a file on startup
